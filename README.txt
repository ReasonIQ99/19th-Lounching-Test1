ReasonIQ99 responsive launch page
================================

This is a real responsive landing page, not a full-page poster. It uses your supplied logo as a separate asset and adapts to mobile and desktop screens.

Files to upload together to the root of your GitHub Pages repository:
- index.html
- logo.png
- favicon.ico
- favicon.png
- site.webmanifest
- robots.txt
- sitemap.xml

HTTPS / GitHub Pages:
1. Repository > Settings > Pages.
2. Set the custom domain to reasoniq99.in if it is not already configured.
3. Enable "Enforce HTTPS" when GitHub makes the option available.
4. Check that DNS records point to GitHub Pages and wait for certificate provisioning if the checkbox is unavailable.
5. Test https://reasoniq99.in/ and https://reasoniq99.in/favicon.ico.

SEO/logo notes:
- The page includes canonical and Open Graph metadata and favicon/apple-touch-icon links.
- Google search result icons are not guaranteed immediately. Google must recrawl the site and may take days or longer.
- Search Console: verify the domain, inspect https://reasoniq99.in/, then request indexing.
- Ensure the logo image is square and clear at small sizes. The supplied logo was used to generate logo.png and favicon files.
- Keep all files in the site root because the HTML references root-relative paths.
